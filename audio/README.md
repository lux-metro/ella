# Directorio de Audio

> En esta carpeta tenés que poner los archivos de audio (.wav, .flac, .ogg o .mp3) que va a reproducir el sistema.

El motor de audio lee esta carpeta automáticamente. Si la carpeta está vacía, el sistema va a esperar sin fallar hasta que pongas algún archivo acá.

Como decidimos incluir los archivos de audio dentro del repositorio git:
1. Simplemente copiá tus archivos a esta carpeta.
2. Hacé el commit y push normalmente.

> ⚠️ **Nota sobre archivos muy grandes:** Si en algún momento los archivos de audio empiezan a pesar muchos cientos de megabytes, puede que GitHub no te deje subirlos o que el repositorio se vuelva muy lento. En ese caso, avisame y configuramos Git LFS (Large File Storage).
